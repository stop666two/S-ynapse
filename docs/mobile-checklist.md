# 移动端真机点检清单

本清单用于 iOS Safari 与 Android Chrome 的真机发布前点检。它与本地自动化模拟互补：

- 自动化模拟（`.tmp-scripts/run-mobile.js`，本地工具）：12 个代表页 × 375×812 / 768×1024 双视口，断言无横向溢出、导航/搜索/TOC 可交互、图片不溢出、0 控制台错误；
- 真机点检（本清单）：覆盖模拟环境无法复现的安全区、软键盘、系统手势、权限、字体回退与滚动性能。

点检前准备：清空浏览器缓存与站点数据（验证首次访问路径）；准备系统「浅色/深色」两种外观；准备横竖屏；连接到可访问的预览或生产地址；长文页面建议使用站内「长文压力测试」文章。

结果记录：每条勾选后，若不符合预期，在「问题记录」中写明设备、系统版本、复现步骤与截图位置。任一条不通过即视为发布阻断，修复后需重新点检对应条目。

## iOS Safari（iOS 16+，Safari 最新版）

- [ ] 1. 安全区适配（竖屏）：底部导航与浮动按钮不被 Home 指示条遮挡，页面底部预留安全区留白；顶部公告条不被状态栏/刘海裁切。预期：所有交互控件完整可见且可点。
- [ ] 2. 安全区适配（横屏）：左右两侧不被刘海/圆角裁切；横屏后底栏、TOC 按钮、返回顶部仍在可视区内。预期：无控件越出安全区。
- [ ] 3. 首屏与图片加载：首屏无长时间白屏；滚动时图片按需加载且不引起布局跳动（CLS 可感知范围内）。预期：滚动过程无内容「跳一下」。
- [ ] 4. 软导航（无刷新跳转）：首页点文章卡片进入文章页，URL 与标题更新、无整页闪白；再返回首页。如站点提供「页面加速」开关，需开/关双态各验证一次。预期：开=无整页刷新；关=正常整页跳转。
- [ ] 5. 边缘返回手势：文章页右滑返回，回到上一页后内容与滚动位置正确（软导航 popstate 恢复）。预期：不出现空白页或错页。
- [ ] 6. 汉堡菜单：点击右上角菜单可展开，菜单项可点、可滚动；再次点击或点遮罩可收起。预期：全程无卡死、无遮挡不可点区域。
- [ ] 7. 文章 TOC 抽屉：文章页打开左下/右下角目录按钮，底部抽屉弹出，点击条目跳转到正确标题并收起。预期：锚点定位不被吸顶头部遮挡。
- [ ] 8. 搜索弹层：点击搜索入口弹出层并自动聚焦输入框，软键盘弹起不遮挡输入行；输入中文与英文关键词均返回结果；关闭后页面滚动位置保持。预期：结果正确、可继续滚动阅读。
- [ ] 9. 弹窗公告：首次访问弹出公告；×、遮罩（如支持）、外接键盘 Esc 均可关闭；关闭后刷新不再弹出（会话/每日频率记忆生效）。预期：关闭状态可预期且不反复打扰。
- [ ] 10. 暗色模式：切换暗色后头部、代码块、表格、公告、底栏、弹层均正确着色；系统切换到深色外观并刷新时首屏无闪白（无 FOUC）。预期：无白底黑字残留、无闪烁。
- [ ] 11. 横屏旋转：竖屏转横屏再转回，布局自适应、无横向溢出；宽公式、表格、代码块在自身容器内横向滚动而不撑破页面。预期：文档级无横向滚动条。
- [ ] 12. 双击与捏合缩放：双击放大、双指缩放均可用（页面未禁用缩放）；放大后固定控件位置正确。预期：缩放可用且不影响正常阅读。
- [ ] 13. CJK 字体：中文以自托管 Noto Sans SC 子集渲染，无缺字/豆腐块；飞行模式（或断网）刷新后回退系统字体，内容仍可读。预期：无方框、无字重错乱。
- [ ] 14. 分享与朗读（TTS）：分享按钮调起系统分享面板（不可用时回退复制链接并提示）；TTS 首次朗读出现权限/手势要求时按提示操作，开始/停止正常，锁屏后停止。预期：权限流程清晰，无静默失败。
- [ ] 15. 图片灯箱：点图打开灯箱，左右滑动切图、捏合缩放、关闭按钮可点且不误触；长按不触发系统图片菜单（如站点策略如此）。预期：手势与关闭均正常。

## Android Chrome（Android 11+，Chrome 最新版）

- [ ] 1. 安全区适配：手势导航条不遮挡底部导航与浮动按钮；挖孔屏下状态栏与公告条不重叠。预期：控件完整可点。
- [ ] 2. 软导航：点击站内链接无整页刷新，URL/标题更新，进入文章后目录、阅读进度、返回顶部等模块正常工作。预期：与整页导航功能一致。
- [ ] 3. 系统返回键：物理返回或手势返回与浏览器后退一致，恢复上一页内容与滚动位置。预期：不会退出站点或出现错误页。
- [ ] 4. 汉堡菜单与底部导航：汉堡可开合、菜单项可点；底部导航各项≥44px 且间距足够，不易误触。预期：点击命中准确。
- [ ] 5. TOC 抽屉：打开/关闭流畅，锚点跳转正确，阅读进度与抽屉进度同步。预期：跳转后当前位置高亮正确。
- [ ] 6. 搜索弹层：软键盘弹起后结果列表仍可滚动查看；中文输入法组合输入过程中可正常出结果、无重复触发。预期：输入法兼容良好。
- [ ] 7. 弹窗公告：每日/会话频率记忆按预期工作；关闭路径（×/遮罩/按钮）均可用；旋转屏幕后弹窗尺寸正常。预期：不出现半屏或超出视口。
- [ ] 8. 暗色模式与对比度：暗色下正文、次要文字、按钮、标签对比度正常；系统「深色主题」与站内切换不冲突。预期：可读性达标（WCAG 2.2 AA）。
- [ ] 9. 横屏与软键盘：横屏无横向溢出；软键盘收起后视口恢复、不残留空白。预期：滚动与点击位置正确。
- [ ] 10. 双击与捏合缩放：双击放大、捏合缩放可用；放大后底栏、返回顶部按钮不错位、不遮挡内容。预期：缩放体验正常。
- [ ] 11. CJK 字体与回退：中文渲染无缺字；断网后回退系统字体仍可读；无字体加载引起的明显闪烁。预期：文本稳定。
- [ ] 12. 分享与朗读（TTS）：Web Share 调起系统分享；不可用时复制链接并提示；TTS 朗读开始/停止、后台切换后停止。预期：无权限报错堆积。
- [ ] 13. 滚动性能：长文快速滚动、上下反复滚动无明显掉帧或白屏；打开开发者工具 Performance 录制无持续长任务。预期：主观流畅、无卡顿。
- [ ] 14. 浮动控件不重叠：返回顶部、阅读工具栏、TOC 按钮与底部导航两两不重叠、互不遮挡点击。预期：每个控件都可单独点击。
- [ ] 15. 灯箱手势：滑动切换图片、双指缩放不越界、下滑/关闭按钮关闭后页面滚动位置保持。预期：手势与桌面端行为一致。

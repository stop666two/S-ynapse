# 关于我

欢迎来到 S-ynapse！这是一个基于 Cloudflare 生态的极简、安全、高性能静态博客系统。

## 技术栈

- **前端**: 静态 HTML + CSS 自定义属性
- **构建**: Node.js + EJS + marked
- **部署**: Cloudflare Pages / Workers
- **图片**: sharp 处理管线

## 项目特点

- 全配置驱动，6 个 JSON 文件控制一切
- 所有非核心功能均支持一键关闭
- URL 由一级标题自动 Slug 化
- 内置 CSP、SRI 等安全机制

# 隐私政策

**最近更新：2026 年 7 月 19 日**

我们重视您的隐私。本隐私政策说明本博客如何收集、使用和保护您的个人信息。

## 信息收集

### 主动提供的信息

当您通过评论系统、联系表单或电子邮件与我们联系时，我们可能会收集您主动提供的以下信息：

- 用户名或昵称
- 电子邮件地址
- 评论内容

### 自动收集的信息

本博客为纯静态站点，托管于 Cloudflare 全球网络，服务器不记录访问日志。但我们使用的第三方服务可能会自动收集以下信息：

- **页面访问统计**：匿名化访问次数和页面浏览量
- **浏览器信息**：浏览器类型、操作系统、屏幕分辨率（用于优化显示）
- **引用来源**：您从哪个网站链接进入本站

## 信息使用

我们收集的信息仅用于以下目的：

- 回复您的评论和咨询
- 改进博客内容和用户体验
- 了解内容受欢迎程度

## Cookie 说明

本博客本身不使用 Cookie。但以下第三方服务可能使用 Cookie：

| 服务 | 用途 | Cookie 类型 |
|------|------|------------|
| Cloudflare | 网络安全与加速 | 必要型 |
| Google Fonts | 字体加载 | 功能型 |
| Giscus / Disqus | 评论系统（如启用） | 功能型 |

您可以在浏览器设置中管理或删除 Cookie。

## 第三方服务

本博客集成了以下第三方服务：

- **Cloudflare** — CDN 加速与 DNS 解析，[隐私政策](https://www.cloudflare.com/privacypolicy/)
- **Google Fonts** — 网络字体加载，[隐私政策](https://policies.google.com/privacy)
- **GitHub** — 代码托管与 Issues 评论，[隐私政策](https://docs.github.com/privacy)
- **jsdelivr** — CDN 资源分发，[隐私政策](https://www.jsdelivr.com/terms/privacy-policy)

## 数据存储与传输

您的评论数据存储在 GitHub 服务器上，可能传输至境外服务器。提交评论即表示您同意此数据传输。

## 数据安全

我们采取合理的技术措施保护您的数据安全：

- 全站 HTTPS 加密传输
- CSP 内容安全策略防止 XSS 攻击
- 外部链接安全警告机制
- 所有静态资源使用子资源完整性（SRI）校验

## 您的权利

根据《个人信息保护法》，您享有以下权利：

- **知情权**：了解您的信息如何被处理
- **删除权**：要求删除您的评论数据
- **撤回同意权**：随时撤回对数据处理的同意

如需行使上述权利，请通过下方联系方式联系我们。

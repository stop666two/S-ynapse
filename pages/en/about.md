## Projects

### S-ynapse

A minimal-first static blog system that runs entirely on the Cloudflare ecosystem. Fully configuration-driven, security-hardened and high-performance. JSON5 config, Markdown authoring, one-click deploy.

**Highlights**:

- 13 JSON5 config files drive every behavior (site / theme / features / ui-strings / tuning / guard / navigation / sidebar / footer / security / content-policy / tag-aliases / friends)
- 14-step build pipeline: config validation, media optimization, CJK typography, TOC, related posts
- Comprehensive security: CSP, external-link allowlist, rate limiting
- Rich interactions: dark mode, full-text search, reading mode, code copy
- Auto-generated OG images, build reports, unit tests
